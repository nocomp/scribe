🌐 Configuration du hostname public

Définit l'URL utilisée pour les liens entre composants SCRIBE
Quand configurer ? Si vous accédez à SCRIBE depuis un VPS, un serveur LAN, ou un hostname public (ex: vps-xxx.ovh.net), configurez ici la valeur exacte à utiliser dans les liens entre instances et collecteurs. Sans configuration, SCRIBE détecte automatiquement le hostname à partir de la requête en cours (suffisant pour la plupart des cas).

Notes techniques :
• La valeur est stockée dans hostname.conf à la racine du projet.
• La variable d'environnement SCRIBE_EXTERNAL_HOST est prioritaire si définie.
• Pour appliquer un changement, redémarrez les instances exercice en cours (collecteur compris).
• Pour revenir à l'auto-détection : supprimer le fichier hostname.conf et redémarrer.
