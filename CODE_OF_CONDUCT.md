# Code of Conduct

SCRIBE adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

In short:

- Be respectful and constructive in discussions
- No harassment, no insults, no discrimination
- Criticize ideas, not people
- Acknowledge others' contributions
- In case of disagreement, seek compromise and technical arguments

Any inappropriate behavior can be reported to the maintainer:

- **Email**: hpellarin @ ch-annecygenevois.fr
